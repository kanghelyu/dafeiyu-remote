## 必须保留的边界

- 产品是“开源、跨平台、支持自建中继集群的高性能远程桌面系统”，不是仅有一个远控窗口的演示。
- Windows、Linux、macOS、Android 都要求主控与被控角色；Android 原生权限限制需要明确说明，但不等于取消被控目标。
- 第二阶段已包含 Windows 与 Linux 的主控、被控、基础串流、键鼠、剪贴板、P2P、Linux 中继、手动中继和自动回退。macOS/Android 的后续实施顺序不删除它们的角色。
- Linux 是初始必需的中继部署平台。自建中继、任意数量中继配置和易部署体验是核心目标，不能放成“可选P2”。
- 虚拟显示是独立核心模块；接口、规格校验或驱动骨架不能代替无头、动态模式、多虚拟屏及驱动恢复的真实验收。
- P2P↔Relay 必须是保留安全状态和业务进度的可恢复会话迁移。新建连接后恢复视频、单独状态机测试或断开重连都不能冒充完成迁移。
- 剪贴板按连接授权、方向和同步策略工作；不得未授权静默传输敏感内容。后端支持某格式，不代表应用默认权限正确。
- 完整能力要靠实际平台、路径和场景验证；编译、mock、loopback、同机实验、跨机实验分别记账。未测不标完成。
