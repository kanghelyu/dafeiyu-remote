## 3. 平台组件与权限边界

| 平台 | 观察到的组件 | 权限/系统边界 |
| --- | --- | --- |
| Windows | 主应用、回环本地控制服务、插件管理服务、CLI、终端桥接组件 | 既有笔记确认本地服务监听与 CLI 通信；UAC/管理员、驱动、辅助功能、安全中心放行等均未核实 |
| macOS | 主应用、用户 Agent、LaunchDaemon、服务/服务器 helper、XPC helper、更新器、CLI、流媒体库 | 依赖 ScreenCaptureKit、CoreGraphics、VideoToolbox、CoreAudio/AVFoundation、Metal、GameController、IOKit；声明麦克风/蓝牙权限，UI 提示录屏/系统录音、辅助功能、文件与文件夹/完全磁盘访问；实际 TCC 授权 U |
| Linux | GUI、server、systemd socket/service、healthd、升级器、CLI、WebView host、流媒体/编解码探测、终端桥接 | 安装器要求 root、Ubuntu 18.04+ 与 systemd；运行依赖 X11/XKB/XFixes、PulseAudio、PipeWire、Vulkan、WebKitGTK/Qt；Wayland/PipeWire 路径存在，但门户授权、锁屏扩展与原生 Wayland 完整性 U |
| Android | 主控/被控/屏幕/终端 Activity、无障碍服务、MediaProjection 被控前台服务、传输与 WOL 前台服务、更新服务、原生流媒体/输入库 | Manifest 声明网络/Wi-Fi、录音、MediaProjection 前台服务、悬浮窗、外部存储、通知、相机/生物识别、安装包等权限；无障碍需用户开启；真实授权、厂商后台限制、API 兼容与撤权行为 U |

Linux 安装脚本中的锁屏远程桌面扩展是可选第三方组件，默认不安装，不应算作 UU 内置能力。macOS 的 LaunchAgent/LaunchDaemon 与 Android 的前台服务也只证明部署结构，不证明锁屏、无头或后台恢复可用。
